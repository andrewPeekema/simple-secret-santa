Simple Secret Santa — visual system mockup

Direction A, with the three-step scale you asked for. The top section is the whole rulebook; the screens below use nothing else. Each phone frame is 412 px wide (Pixel 9). Current app for comparison.

Section-title treatment:

Type — three steps, two faces

Heading · 24 serif

Page titles and the recipient's name.

Body · 16 sans

Everything you read or press: inputs, buttons, instructions, section titles (medium weight).

Section titles: serif at body size (variant B).

Note · 13 sans, muted — help text, warnings, link URLs, the password label. The app works if you never read one.

Sentence case everywhere. No ALL CAPS, no Title Case, no text-transform.

Letter-spacing only on the mono password and the stars.

Font weights: 400 and 500. Drop the 600/700 loads.

No italics anywhere; the italic font load goes too.

Colour — named by role

bg-0 · page
bg-1 · card
bg-2 · inputs, inset boxes
text-1 / text-2 / text-3
accent — one green, plus its tint
gold — recipient's name and stars only
star-ice / star-silver — the title stars only
danger — remove, errors, warnings

Removed: green-light, green-dark, red-light, the pink glow, and the 3 unused + 5 duplicate tokens. The five star colours stay, as named tokens.

Fixes the copy-button bug: the "Copied!" state is a class, not an inline colour.

Controls — three buttons, one height

Was: 7 button variants, 4 sizes, 2 hover colours, no filled primary.

Surfaces: card (bg-1) → inset (bg-2) → tint (accent or danger). That's all three box kinds; was ~11.

Radius 6px (8px on cards). Spacing on a 4px grid: 4 / 8 / 12 / 16 / 24 / 32.

All 30 inline style= attributes move into these classes.

One container level per screen. Sections are separated by hairline rules, not nested boxes. Tint is reserved for status (links ready / warning).

One primary button per screen. Navigation (back, start over) is a quiet text link.

How it works
  1. Generate pairings by entering participant names below
  2. Share each link privately with the right person
  3. Each person sees their assignment and gets a wishlist password
  4. Wishlists are optional—each person can create one for their Santa

Wishlists are gift-wrapped, not locked up. Keep anything private off them. 🎁

This site doesn't store or collect any data—everything runs locally in your browser.
